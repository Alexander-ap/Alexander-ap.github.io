欢迎来到我的博客。

这是用 **Hexo 8** + 自建主题 **kpmark** 搭的，托管在 GitHub Pages。

## 常用命令

```bash
hexo new "文章标题"     # 新建文章
hexo generate           # 编译成静态文件到 public/
hexo server             # 本地预览 http://localhost:4000
hexo clean              # 清理缓存和 public/
hexo deploy             # 部署（配置好 git 之后可用）
```
